## 造型与出处

在设定板预览里，Muse 留着粉白至蓝色的渐变卷发，戴细框圆眼镜和蓝色 ∞ 发夹。白蓝外套与蓝色高领针织上衣叠穿，搭配左腿环和蓝白洞洞鞋。发布者称发顶的一对白耳为羊驼耳。表情区可见眯眼笑、得意和委屈，道具区有自拍手机和 Jolly 玩偶。[设定板预览](https://github.com/lmy414/ai-chan-sheets/blob/415238bfdafa0fc153c8c0098e8efd4b57b2d5a5/docs/previews/19.webp)

设定板目录列出 3 张视图、8 张表情、4 项服装和 7 项道具与饰品。lmy414 基于已收录立绘做设定板补全，侧面、背面、遮挡结构和部分表情含生成推定。[设定板说明和分项素材](https://github.com/lmy414/ai-chan-sheets/blob/415238bfdafa0fc153c8c0098e8efd4b57b2d5a5/%E8%AE%BE%E5%AE%9A%E5%9B%BE/19_Muse%E5%A8%98_Meta_AI/README.md)
