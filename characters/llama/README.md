## 形象与版本

署名：ZipZipPipe。

检索别称：Llama娘、羊驼娘。

该页主要参考版本的识别点：

- 白色长卷发
- 白色猫耳
- 宽松白色外套

名字可译羊驼，但这套资料的外形描述是猫耳；不要仅凭产品名擅自改掉耳朵。 本轮作者来源将耳部与拖鞋归为羊驼意象；聚合页的猫耳描述保留为旧来源差异，不能据动物耳形单独判角色。

## 本轮新增与扩写的作者版本

### 校园系列 · school-op

原创校园分支；区别白发宽外套的ZipZipPipe版本。

识别点：蜂蜜金卷发；奶油色羊驼耳与短尾；蓝色无穷徽章。
