# Gemini

资料日期：2026-10-21。类型：`model-family`；状态：`local_assets`。

## 形象与版本

署名：ZipZipPipe。

检索别称：Gemini娘、双子娘、猫娘。

该页主要参考版本的识别点：

- 蓝紫渐变长发
- 猫耳猫尾
- 异色瞳与星形元素

猫耳轮廓与蓝紫色组合比单独的星标更有辨识度。OpenPet的彩虹发版本是另一套设计。

## 本轮新增与扩写的作者版本

### 校园系列 · school-op

保留猫娘轮廓；常服图、校园图分别管理。

识别点：蓝紫长发与猫耳猫尾；异色瞳；彩色领结。

[作者发布的提示词文件](https://github.com/lshhhhhhh/ai-school-op/blob/379e83eebe0f5c34eefa81ca4ef8203c1c54ae64/cast/designs/gemini.prompt.txt)。这是该派生系列的提示词，不冒充早期原角色提示词。

### ApprenTice 常规/Q版 · apprentice

常规比例与Q版为ApprenTice重新制作的两张派生图，均有完整文件；不是ZipZipPipe原始Q版，也不是视频截帧。

识别点：蓝紫渐变长发；猫耳猫尾；异色瞳与星形元素。

[作者发布的提示词文件](https://github.com/Apprentice-Geo/AI-Fanworks/blob/ee1f5176710f3bcfd60ee5cb0af00f77ed96748e/ApprenTice/AI-Girls-and-Chibis/Prompts.md)。这是该派生系列的提示词，不冒充早期原角色提示词。
