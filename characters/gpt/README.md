## 本轮新增与扩写的作者版本

### 校园系列 · school-op

本项目原创人设，不能当作龙娘的单纯换装。

识别点：银白中长发；灰绿眼与绿色领结；人类耳、无龙翼尾。

[作者发布的提示词文件](https://github.com/lshhhhhhh/ai-school-op/blob/379e83eebe0f5c34eefa81ca4ef8203c1c54ae64/cast/designs/gpt.prompt.txt)。这是该派生系列的提示词，不冒充早期原角色提示词。

### ApprenTice 常规/Q版 · apprentice

常规比例与Q版为ApprenTice重新制作的两张派生图，均有完整文件；不是ZipZipPipe原始Q版，也不是视频截帧。

识别点：白色长发；龙角、龙翼与长尾；浅色礼服。

[作者发布的提示词文件](https://github.com/Apprentice-Geo/AI-Fanworks/blob/ee1f5176710f3bcfd60ee5cb0af00f77ed96748e/ApprenTice/AI-Girls-and-Chibis/Prompts.md)。这是该派生系列的提示词，不冒充早期原角色提示词。

### GPT Dragon Girl · community-pet

legeling independently generated this white-and-lavender winged chibi V2 edition, visually approved on 2026-10-07. It uses its own nine action sequences and sixteen look poses; it is distinct from tenghuan123's GPT Dragon Girl edition in PR #253 and orient37's homewear Codex Dragon Girl in PR #252.

本轮读取元数据，未下载图集或进行原生运行。

### GPT龙娘 · community-pet

tenghuan123 独立制作的 V2 Q 版，包含九组动画和 16 个环视方向；与其他作者的版本使用不同的图集。

本轮读取元数据，未下载图集或进行原生运行。
