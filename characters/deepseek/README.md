## 形象身份

设计或资料署名：上善无形（原角色）；ZipZipPipe（二次设计）。

检索别称：蓝色大肥鱼、鲸鱼娘、DS娘、Whale-chan。

已见资料中的识别点：

- 蓝色长发
- 鲸鱼鳍状耳饰与鲸尾
- 深蓝白女仆裙

## 版本与易混点

鲸尾末端左右尾鳍属于一条尾巴；女仆装、宫廷侍女装、小肥鱼及DSH方案分别建版本。不能把所有蓝发鲸鱼图归成同一作者。

## 创作时可以怎样使用

可用饭碗、清单或休息动作表现日常反差；这是创作建议，吃饭摸鱼不是技术能力评价。
