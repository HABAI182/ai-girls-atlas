# DeepSeek / 深度求索

资料日期：2026-10-21。类型：`model-family`；状态：`local_assets`。

## 形象与版本

署名：上善无形（原角色）；ZipZipPipe（二次设计）。

检索别称：蓝色大肥鱼、鲸鱼娘、DS娘、Whale-chan。

该页主要参考版本的识别点：

- 蓝色长发
- 鲸鱼鳍状耳饰与鲸尾
- 深蓝白女仆裙

鲸尾末端左右尾鳍属于一条尾巴；女仆装、宫廷侍女装、小肥鱼及DSH方案分别建版本。不能把所有蓝发鲸鱼图归成同一作者。

## 本轮新增与扩写的作者版本

### 校园系列 · school-op

女仆元素改为共用校服，鲸类识别点继续保留。

识别点：蓝色长卷发与呆毛；鲸鳍耳和一条鲸尾；蓝色领结。

常规比例与Q版为ApprenTice重新制作的两张派生图，均有完整文件；不是ZipZipPipe原始Q版，也不是视频截帧。

识别点：蓝色长发；鲸鱼鳍状耳饰与鲸尾；深蓝白女仆裙。

[作者发布的提示词文件](https://github.com/Apprentice-Geo/AI-Fanworks/blob/ee1f5176710f3bcfd60ee5cb0af00f77ed96748e/ApprenTice/AI-Girls-and-Chibis/Prompts.md)。这是该派生系列的提示词，不冒充早期原角色提示词。

### DeepSeek Girl · community-pet

An original v2 DeepSeek Girl community interpretation: a blue-haired whale girl with head fins, an attached whale tail, an original deep-sea maid outfit, nine task animations, and sixteen clockwise look directions.

本轮读取元数据，未下载图集或进行原生运行。

### DeepSeek Whalechan · community-pet

An independent qimi variant of the existing DeepSeek whale-girl entry: a super-deformed blue maid design with a notebook/ChatGPT mark and a distinct running row whose row1 frames are mirrored from row2. The spritesheet is independently generated and byte-distinct from the existing entry.

本轮读取元数据，未下载图集或进行原生运行。
