- 橙色长发
- 花形发饰

## 本轮新增与扩写的作者版本

### 校园系列 · school-op

保留早期暖色识别点，换成校园服装；不同于黑紫工程服。

识别点：橙色长发与花形发饰；橙红领结；灰蓝校服裙。

[作者发布的提示词文件](https://github.com/lshhhhhhh/ai-school-op/blob/379e83eebe0f5c34eefa81ca4ef8203c1c54ae64/cast/designs/claude.prompt.txt)。这是该派生系列的提示词，不冒充早期原角色提示词。

### ApprenTice 常规/Q版 · apprentice

常规比例与Q版为ApprenTice重新制作的两张派生图，均有完整文件；不是ZipZipPipe原始Q版，也不是视频截帧。

识别点：橙色长发；花形发饰；米白橙黑层叠长裙与书本。

[作者发布的提示词文件](https://github.com/Apprentice-Geo/AI-Fanworks/blob/ee1f5176710f3bcfd60ee5cb0af00f77ed96748e/ApprenTice/AI-Girls-and-Chibis/Prompts.md)。这是该派生系列的提示词，不冒充早期原角色提示词。

### 作者工程服形象版本 · zipzippipe

安全帽与工装上有 CLAUDE 字样，与初始礼服不是同一张。

识别点：黑紫龙角与翅膀；安全帽和工装；CLAUDE/C标识。
