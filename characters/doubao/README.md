## 形象与版本

署名：豆包/字节跳动（官方头像）；其他版本各自署名。

检索别称：豆包、Doubao、豆包娘。

该页主要参考版本的识别点：

- 官方短发头像有来源
- 同人造型存在多个分支

Seed娘不是所有豆包形象的同义词；官方头像、ZipZipPipe的Seed版、OpenPet版、网络夸张梗图应并列。
