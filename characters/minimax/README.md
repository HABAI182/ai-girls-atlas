该页主要参考版本的识别点：

- 橙色短发
- 粉色贝雷帽

海螺是相关产品称呼，不表示品牌旗下每项服务都有同一角色。帽子和场记板组合是本版强识别点。

## 本轮新增与扩写的作者版本

### 校园系列 · school-op

保留暖色短发方向，不带贝雷帽和场记板。

识别点：桃橙色短发；珊瑚色发夹；珊瑚色领结。

[作者发布的提示词文件](https://github.com/lshhhhhhh/ai-school-op/blob/379e83eebe0f5c34eefa81ca4ef8203c1c54ae64/cast/designs/minimax.prompt.txt)。这是该派生系列的提示词，不冒充早期原角色提示词。

### ApprenTice 常规/Q版 · apprentice

常规比例与Q版为ApprenTice重新制作的两张派生图，均有完整文件；不是ZipZipPipe原始Q版，也不是视频截帧。

识别点：橙色短发；粉色贝雷帽；场记板、照片与创作道具。

[作者发布的提示词文件](https://github.com/Apprentice-Geo/AI-Fanworks/blob/ee1f5176710f3bcfd60ee5cb0af00f77ed96748e/ApprenTice/AI-Girls-and-Chibis/Prompts.md)。这是该派生系列的提示词，不冒充早期原角色提示词。
