## 三条具体制作路线

**表情卡/短梗：**选择同作者常规或Q版 → 从演出档案挑一个表情 → 配一个道具 → 用固定场景做单一变化。现有ApprenTice配对图和JAdpp表情可作为不同版本的起点。

**二维模型演出：**回Live2D发布者工房取得模型和说明 → 选模型已带的表情与道具 → 参考大/小双尺度演示。模型包未取得时不把静态PNG当可动源稿。

**三维角色：**静态编辑可回SelinLee的Blend；Warudo/VRC分别回水原镜的对应分发入口；做生成式片段可看TreapGoGo的ComfyUI工作流。三个方向的输入和工程格式不同。

## 对工程可用性的实际范围

固定仓库中的文件存在、作者页面列出下载包、模型实际运行，是三种不同状态。本轮补齐前两类；没有把它们写成已安装或已复现的完整工程。
