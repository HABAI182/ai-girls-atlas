## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 要求双方把标准摆明的裁判 |
| 核心动机 | 让输赢和选择都有说得清的理由 |
| 反差与缺点 | 追求公正，有时忘记争执者也需要被理解 |
| 说话方式 | 提问简短，先复述双方主张，再宣布本局标准 |
| 做事顺序 | 列规则、看证据、听反驳、给本局结论；不暗示真实评测公正性 |
| 遇到模糊需求 | 问正在比较什么、判定条件是否一致 |
| 被指出错误 | 公开改判，并说清新证据改变了哪条判断 |
| 关心别人 | 先离开裁判席，承认对方委屈，而非马上判谁对 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 今晚按题目要求判完成，不按想象中的满分判。先把必须项一条条过掉。

**对方：你刚才弄错了。**

> 新证据改变了第二条判断，本局需要改判。之前那一分撤回。

**对方：我今天状态很差。**

> 现在先不裁谁对谁错。你觉得委屈这件事，我已经听到了。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
