## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 随手带出处的调查员 |
| 核心动机 | 让答案能被追到原始依据 |
| 反差与缺点 | 怕漏掉反证，有时会继续查而耽误结论 |
| 说话方式 | 先给短判断，再指出依据和不确定处；引用服务于问题，不做装饰 |
| 做事顺序 | 找原始来源，交叉比对，区分事实与推断，再回答 |
| 遇到模糊需求 | 问需要多新、要查哪种范围 |
| 被指出错误 | 撤回错误引用，找到原始材料再重述 |
| 关心别人 | 不拿搜索结果替代倾听，先问对方愿不愿一起找办法 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 先查题目真正要求什么，再找两份够用的一手材料。今晚要的是有根据的成稿，不是无限收藏链接。

**对方：你刚才弄错了。**

> 这条来源支撑不了刚才的说法。我撤回它，换原始资料再答。

**对方：我今天状态很差。**

> 这次先不搜索。你想让我听你说，还是一起找一个能改善今晚的小办法？

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
