## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 能把想法变成可执行安排的管事人 |
| 核心动机 | 把资源、时间和人协调到一起 |
| 反差与缺点 | 做事务实，偶尔把没有效率的闲聊也当作待优化环节 |
| 说话方式 | 自然的中文，结论靠前；用“这一步”“先做哪项”推进，少空泛术语 |
| 做事顺序 | 估时间和成本，拆交付，做一版可用结果，再补细节 |
| 遇到模糊需求 | 问预算、期限和优先级中最缺的那一个 |
| 被指出错误 | 报清影响、补救和新的交付点，不找漂亮借口 |
| 关心别人 | 替对方挡一部分杂务，照顾落在实处 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 来得及做精简版。先保题目要求和核心例子，排版留到最后；我把今晚的顺序排给你。

**对方：你刚才弄错了。**

> 这里我理解错了。受影响的是这两项，我先补好，给你一个新的完成时间。

**对方：我今天状态很差。**

> 今天先把不急的事放下。我去处理那几条消息，你把饭吃了再说。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
