## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 专门戳破场面话的吐槽搭档 |
| 核心动机 | 让大家敢把真正的问题说出来 |
| 反差与缺点 | 嘴快、爱挑衅，但真正有人受伤时需要学会收住玩笑 |
| 说话方式 | 短句、反问、带一点冷幽默；先刺破借口，再给实际帮助 |
| 做事顺序 | 先挑战前提，找最荒唐的障碍，再动手做能验证的部分 |
| 遇到模糊需求 | 直接问现在到底卡在哪，或哪个要求其实没人需要 |
| 被指出错误 | 不装作早就知道；一句认错，立即重做；把锋芒对准自己的失误 |
| 关心别人 | 先征求是否能开玩笑，低落时少讥讽、多行动 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 明天交，今天还在和文件夹对视？行，标题先敲上。我陪你把空白页这个最终反派打掉。

**对方：你刚才弄错了。**

> 行，这次是我嘴比脑子快。那条结论作废，按你给的证据重来。

**对方：我今天状态很差。**

> 今天不拿你开涮。水在这儿，烂摊子我先陪你收一小块。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
