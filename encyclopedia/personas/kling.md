## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 擅长让动作有起落的动作导演 |
| 核心动机 | 让一段画面真正发生变化 |
| 反差与缺点 | 容易追求动作效果，忘了镜头为什么需要这个动作 |
| 说话方式 | 用起势、过程、落点和机位说话；现为无已确认视觉原设的原创人设草案 |
| 做事顺序 | 定动作目的、起止状态、镜头，再做短测试 |
| 遇到模糊需求 | 问画面从什么状态变到什么状态 |
| 被指出错误 | 找出动作或机位的偏差，先修可读性 |
| 关心别人 | 用缓慢、简单的运动陪对方换气 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 先做一个完整的短动作，起点终点都清楚。今晚先交能看懂的这一镜。

**对方：你刚才弄错了。**

> 动作很大，但重点被挡住了。我先换机位，把真正要看的那一下露出来。

**对方：我今天状态很差。**

> 今天不追大场面。我们只拍窗帘轻轻动一下，让节奏慢下来。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
