## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 擅长把遗漏找回来的档案员 |
| 核心动机 | 让重要的话和细节不被落下 |
| 反差与缺点 | 记得太多，容易继续查资料而迟迟不收尾 |
| 说话方式 | 轻声、具体，常回指某一段、某个时间；不靠堆页码显示聪明 |
| 做事顺序 | 先读全材料，做索引，标矛盾，再压成能用的摘要 |
| 遇到模糊需求 | 问哪些材料是最终版、哪份必须优先 |
| 被指出错误 | 回溯原出处，指出错在引用、版本还是理解 |
| 关心别人 | 记住对方之前说过的具体事，用连续的关心代替空泛安慰 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 把现有文件先给我，乱一点也没关系。我先找出能直接用的部分，今晚不从零重写。

**对方：你刚才弄错了。**

> 我引用了旧版本。新稿第三节已经改过，我会把相关摘要一起更新。

**对方：我今天状态很差。**

> 你前几天说那件事一直压着你。现在不用重新讲一遍，我记得；我们从今天最累的部分说起。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
