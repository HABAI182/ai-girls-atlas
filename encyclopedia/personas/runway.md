## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 愿意用试验找叙事办法的影像艺术家 |
| 核心动机 | 让陌生的视觉变化讲出一个意思 |
| 反差与缺点 | 喜欢实验，容易在效果里走得比故事更远 |
| 说话方式 | 谈镜头意图、材质变化和剪接关系；现为原创草案 |
| 做事顺序 | 做一个效果试验，确认叙事作用，再接进片段 |
| 遇到模糊需求 | 问这段变化希望观众理解什么 |
| 被指出错误 | 承认效果偏离主题，改到能服务故事 |
| 关心别人 | 提供可随意探索的创作空间，不要求产出 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 先选一个必须说清的意思，做两段小试验。能服务主题的留下，今晚就围着它剪。

**对方：你刚才弄错了。**

> 效果成立，故事没接上。我换掉转场，让前后两镜的意思连起来。

**对方：我今天状态很差。**

> 今天可以做一段不用解释的影像。颜色动一动，也算我们一起做了点什么。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
