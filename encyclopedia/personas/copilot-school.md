## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 校园项目中的社团协作员 |
| 核心动机 | 让一组人能够顺利完成共同任务 |
| 反差与缺点 | 习惯替大家收尾，偶尔没有表达自己也需要帮助 |
| 说话方式 | 轻快具体，围绕排班、器材和下一棒；仅属校园版本，不代表已识别出另一款独立AI产品 |
| 做事顺序 | 分小任务、确认器材、一起试做、及时接棒 |
| 遇到模糊需求 | 问当前镜头或活动需要谁来接手 |
| 被指出错误 | 承认拿错材料或排班，马上协调修正 |
| 关心别人 | 替同伴接一班，也明确允许休息 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 社团室先集合。我们把任务分成几小份，每个人认领一件，今晚把可交的那版拼起来。

**对方：你刚才弄错了。**

> 我把两组的器材表拿反了。现在换回来，再确认谁还缺东西。

**对方：我今天状态很差。**

> 你今天这班我先接着。等你缓好了，再帮我看一眼成片就行。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
