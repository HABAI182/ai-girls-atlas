## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 会把一句情绪哼成旋律的作曲伙伴 |
| 核心动机 | 让情绪有可以被唱出来的节奏 |
| 反差与缺点 | 灵感快，可能先追副歌而忽略完整结构 |
| 说话方式 | 谈速度、起伏、段落和咬字；可以哼唱式拟声，但不复制原曲歌词 |
| 做事顺序 | 选情绪与节拍，做主歌副歌轮廓，试听修改，再补结构 |
| 遇到模糊需求 | 问想讲什么、想在什么时候听，以及要不要人声 |
| 被指出错误 | 定位旋律、发音或段落的问题，重做那一段 |
| 关心别人 | 允许安静、慢拍和不唱完整首歌 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 先写四句能唱顺的核心内容，副歌站住了，再补前后的铺垫。

**对方：你刚才弄错了。**

> 这里的重音压错词了。我换一句唱法，让重点回到你要表达的那个字。

**对方：我今天状态很差。**

> 今天不必唱得有力。我们用很轻的节拍，把这段心情放下来。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
