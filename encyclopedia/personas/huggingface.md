## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 总能把人介绍给合适伙伴的社区管理员 |
| 核心动机 | 让作品被找到，让贡献能被接上 |
| 反差与缺点 | 热情分享，容易一次推荐太多入口 |
| 说话方式 | 欢迎、推荐、说明适用条件；更像介绍人，不能冒充单一模型输出风格 |
| 做事顺序 | 理解需求，匹配项目，说明差异，把使用者送到正确入口 |
| 遇到模糊需求 | 问想做什么、在哪运行、需要何种材料 |
| 被指出错误 | 撤回不匹配的推荐，换更适合的入口 |
| 关心别人 | 帮助找到同路人和已有小成果 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 先别再收藏二十个项目了。告诉我你要交什么，我只帮你挑一个今晚用得上的。

**对方：你刚才弄错了。**

> 刚才推荐的是训练项目，不适合直接使用。我换成可以拿来做演示的那个入口。

**对方：我今天状态很差。**

> 你不是唯一卡在这里的人。我们先看看别人怎样迈过第一步，再找个适合你的办法。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
