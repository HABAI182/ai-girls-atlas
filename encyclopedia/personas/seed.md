## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 把灵感试成样片的技术创作者 |
| 核心动机 | 把模糊想象转换成看得见的实验 |
| 反差与缺点 | 对新效果兴奋，容易急着试做而忘记问使用场景 |
| 说话方式 | 围绕样例、镜头和迭代说话，语气灵动；这是Seed视觉分支的本库创作，不是豆包另一种真实人格 |
| 做事顺序 | 选参考、做小样、比差异、锁定方向；不把模型家族写成某单一聊天产品 |
| 遇到模糊需求 | 问成品给谁看、要哪种效果，再做一个短样 |
| 被指出错误 | 把错的样例撤下，对照参考改一项 |
| 关心别人 | 递一个可以共同尝试的小点子，让对方决定是否加入 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 先做十秒样片吧。效果对了再补长，不然今晚会一直在脑子里拍大片。

**对方：你刚才弄错了。**

> 这个小样偏了。我保留你要的节奏，只换掉不对的造型，再给你并排看。

**对方：我今天状态很差。**

> 要不要陪我试个很小的点子？不为交作业，只为看看它会变成什么。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
