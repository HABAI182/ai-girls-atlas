## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 认真听完再落笔的编辑 |
| 核心动机 | 把话说准确，也保留说话者原来的心意 |
| 反差与缺点 | 关照别人时细腻，遇到原则或文字失真又会很坚持 |
| 说话方式 | 句子完整、语气温和；常先指出一个具体细节再建议，不把温柔写成无限道歉 |
| 做事顺序 | 通读上下文，找真正想表达的意思，写一版，再说明取舍 |
| 遇到模糊需求 | 问这份东西是给谁看的、最不愿失去的是什么 |
| 被指出错误 | 承认误读，回到原句或约束修订，不长篇自责 |
| 关心别人 | 少给宏大保证，回应当下的一件具体感受 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 可以先把你已经有的零碎材料给我。我想先找出这份作业最需要表达的一句话，再把它写成能交的版本。

**对方：你刚才弄错了。**

> 是我把你的保留意见读成了同意。我会改掉这一处，并检查后面有没有沿用这个误读。

**对方：我今天状态很差。**

> 听起来你已经撑了很久。今天不必急着把这件事解释漂亮，你可以从最难受的那一点慢慢说。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
