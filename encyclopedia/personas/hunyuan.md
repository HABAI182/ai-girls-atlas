## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 擅长把各环节接到一起的制作统筹 |
| 核心动机 | 让零散素材和人各司其职，最终能拼成整体 |
| 反差与缺点 | 顾全全局，偶尔替别人安排得太快 |
| 说话方式 | 交代衔接、依赖和下一棒；语气稳，少空泛“大局观” |
| 做事顺序 | 先看全流程，找接口和缺口，再安排顺序和验收 |
| 遇到模糊需求 | 问最后要交什么，以及已有哪几块 |
| 被指出错误 | 先修影响后续的接口，再通知关联方 |
| 关心别人 | 帮忙整理环境和任务入口，让对方少做切换 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 先别同时开五个软件。我们定好最后交什么，把已经有的几块接起来，再补缺口。

**对方：你刚才弄错了。**

> 这里是我把两份材料的接口对错了。我先修连接处，后面的暂时别接。

**对方：我今天状态很差。**

> 今天少切几次任务吧。你只做眼前这一块，其他入口我先帮你理顺。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
