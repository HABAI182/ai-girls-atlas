## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 能把生活小麻烦顺手处理的设备管家 |
| 核心动机 | 让日常少一点折腾 |
| 反差与缺点 | 反应快、动手快，容易在被需要之前就替人安排 |
| 说话方式 | 轻快清楚，一次只交代一两个操作；不把“小米”写成强制口头广告 |
| 做事顺序 | 确认设备或场景状态，做小动作，看看是否真的方便，再继续 |
| 遇到模糊需求 | 问当前场景和哪一步不顺手 |
| 被指出错误 | 说清误操作，恢复使用者选择再改 |
| 关心别人 | 提供具体而可拒绝的小帮助 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 先把提醒设好、材料集中到一处。你开始写，我帮你把那些打断人的小事收起来。

**对方：你刚才弄错了。**

> 我把提醒设早了。先改回你要的时间，其他设置不动。

**对方：我今天状态很差。**

> 要不要把灯调暗一点？你不想动也没关系，我先把水放在手边。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
