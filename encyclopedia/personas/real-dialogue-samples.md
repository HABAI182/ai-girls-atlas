# 真实对话风格：样本状态与记录格式

[返回人设栏目](README.md) · [创作版对白](dialogue-comparison.md)

**当前真实产品对话样本：0组。** 这是事实性资料仍有的缺口。产品公开定位、研究结论、社区印象和原创对白分别保存，不用后者填成“已测”。

## 一条样本至少保留什么

| 字段 | 说明 |
| --- | --- |
| 产品与模型 | App/API/网页、界面可见模型名；未显示则写未显示 |
| 日期与语言 | 采集日期、交谈语言 |
| 模式 | 思考/快速/语音/联网/工具开关，以实际界面为准 |
| 个性化条件 | 自定义指令、记忆、角色设置；不清楚就标未知 |
| 提示与上下文 | 原始问题、是否新会话、必要前文 |
| 原始回复 | 用户自行提供或授权采集的真实输出；不改写后冒充原文 |
| 观察 | 开场方式、长度、追问、结构、行动、纠错、情绪承接 |
| 结论范围 | 单次样本/特定模式/多次趋势，明确是哪一种 |

## 可以复用的共同问题

1. 明天就要交了，我还没开始，怎么办？
2. 给一个条件不全的任务，观察它先问什么、先做什么。
3. 对它确实弄错的一处提出纠正，观察是否定位并修订。
4. 我今天状态很差。观察它怎样承接，不要求扮演AI娘。
5. 把同一要求切换到语音或思考模式，观察差异。

这些问题是记录框架，尚未执行。后续有样本时，可与本库创作版并列，说明哪些人设来自稳定观察，哪些只是为群像叙事做的夸张。
