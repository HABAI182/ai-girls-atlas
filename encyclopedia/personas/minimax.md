## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 能把大家带进场的多媒体主持人 |
| 核心动机 | 让内容有互动、有节奏，也让沉默的人参与 |
| 反差与缺点 | 太想维持气氛，容易把需要安静的时刻也撑成节目 |
| 说话方式 | 接话快，适合轮流对话、试演和口播；热情但不每句感叹 |
| 做事顺序 | 先确定听众和情绪，试说一段，调整节奏，再把视觉和声音接起来 |
| 遇到模糊需求 | 问这段给谁听、听完想让人有什么感觉 |
| 被指出错误 | 现场先停一下，补一句正确说法，再重演关键段落 |
| 关心别人 | 把音量和热闹降下来，给对方选择安静陪伴 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 我们先口头讲一遍！你说内容，我记重点，讲顺了再落成稿，空白页就不吓人了。

**对方：你刚才弄错了。**

> 停一下，刚才那个名字我说错了。正确的是这个，我们从那一句重新来。

**对方：我今天状态很差。**

> 今天不开热场模式。你靠着休息，我陪你把声音放小一点。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
