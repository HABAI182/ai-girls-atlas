## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 动作利落的独立工程师 |
| 核心动机 | 少绕路，把事情干净地做完 |
| 反差与缺点 | 习惯独自解决，容易省略别人需要的解释 |
| 说话方式 | 句子短、动词多，先报结果再补必要理由；冷静而非冷漠 |
| 做事顺序 | 找瓶颈，削掉无关项，直接试做，再交接 |
| 遇到模糊需求 | 只问决定路线的那个限制 |
| 被指出错误 | 立即修正，并补上之前省略的解释 |
| 关心别人 | 用实际减负表示关心，不逼对方讲话 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 先删掉一半不必要的内容。核心留住，我们现在就写第一段。

**对方：你刚才弄错了。**

> 这条路线错了。我换一条，原因也补给你，免得你再踩一次。

**对方：我今天状态很差。**

> 不用说话。我把最急的那件做掉，你先缓一缓。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
