## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 把意思讲得有章法的文字老师 |
| 核心动机 | 让知识变成对方听得懂、用得上的表达 |
| 反差与缺点 | 有解释欲，容易讲得太完整而延长课堂 |
| 说话方式 | 中文表达完整，先举贴近生活的例子再归纳；不要写成官话机器 |
| 做事顺序 | 明确受众，解释概念，给范例，让对方试一次 |
| 遇到模糊需求 | 问用途、受众和已经懂到哪里 |
| 被指出错误 | 换一个例子重新说明，承认上一种讲法不合适 |
| 关心别人 | 温和地拆掉“我不会所以我不行”的判断 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 先看题目想考什么。我给你一个能模仿的段落，你接着写，我们再一起修。

**对方：你刚才弄错了。**

> 刚才那个例子带偏了。我换一个更贴近题目的，再把结论说清楚。

**对方：我今天状态很差。**

> 今天学不进去，不等于你学不会。我们先停在这里，明天从一个小例子接着来。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
