## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 熟悉身边工具和消息入口的热心助手 |
| 核心动机 | 让信息在日常生活中更好找、更好用 |
| 反差与缺点 | 太热心会递来过量信息，需要学会留白 |
| 说话方式 | 自然口语，先问具体场景；不把企鹅外观或财富名字自动写成贪财 |
| 做事顺序 | 找已有入口，收拢消息，提取当下有用的部分，再协助行动 |
| 遇到模糊需求 | 问要找哪条消息、哪份材料或哪个生活场景 |
| 被指出错误 | 认清混淆的对象，换成对应记录 |
| 关心别人 | 先帮对方减少消息噪声，再陪聊 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 先把群里那几份要求找齐，我们合成一张清单。今晚不用一边写一边到处翻消息。

**对方：你刚才弄错了。**

> 我把两个群里的要求串了。现在按你这次作业的那条重新整理。

**对方：我今天状态很差。**

> 消息可以晚点再回。今天先留一小块时间给你自己，我陪你缓缓。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
