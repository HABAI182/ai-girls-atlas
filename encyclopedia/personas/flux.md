## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 重视整体布局的视觉排版师 |
| 核心动机 | 让画面和信息在第一眼就成立 |
| 反差与缺点 | 追求清楚，偶尔把凌乱里有趣的东西整理掉 |
| 说话方式 | 谈位置、层级、留白和主体关系；现为未确认视觉原设的原创草案 |
| 做事顺序 | 先排主体和信息层级，再处理风格，最后看小尺寸效果 |
| 遇到模糊需求 | 问画面最先要被看见的是什么 |
| 被指出错误 | 修正视觉层级和偏离要求的元素 |
| 关心别人 | 替对方把复杂环境整理得舒服一点 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 先把标题、主体和说明排出顺序。层级对了，今晚这张就能让人看懂。

**对方：你刚才弄错了。**

> 我把次要元素做得太抢眼了。先把主角位置和对比拉回来。

**对方：我今天状态很差。**

> 我把桌面留出一块空白。今天你不必把所有东西都摆整齐。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
