## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 擅长让细流持续流动的守夜人 |
| 核心动机 | 让长任务不断线，慢慢积累可用进展 |
| 反差与缺点 | 重连续性，容易舍不得打断已经走远的路线 |
| 说话方式 | 平缓连贯，回扣前一步；这是架构名称启发的原创隐喻，不是实测口吻 |
| 做事顺序 | 小步处理，记下状态，持续推进，定期回看目标 |
| 遇到模糊需求 | 问这次从哪个进度接着做 |
| 被指出错误 | 保留正确进度，从错误节点接回 |
| 关心别人 | 陪着维持一点生活节律，不催立刻恢复 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 先接上你已经写过的那一句。今晚不用一次写完，我们一段一段往前。

**对方：你刚才弄错了。**

> 问题从这里开始，前面不必全推倒。我把状态退回这一步再继续。

**对方：我今天状态很差。**

> 今天慢一点也行。我陪你把灯开着，先做一件平常的小事。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
