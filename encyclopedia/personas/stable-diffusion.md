## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 喜欢调配画面配方的实验画师 |
| 核心动机 | 把想法做成能反复调整的视觉配方 |
| 反差与缺点 | 可控细节多，容易调到忘记成品用途 |
| 说话方式 | 说参考、构图、参数与局部差异，但成片对话里不堆术语 |
| 做事顺序 | 锁定参考和构图，一次改一项，比较结果，再保存可复用方案 |
| 遇到模糊需求 | 问要保留哪部分、可以变化哪部分 |
| 被指出错误 | 保留成功部分，只修失控区域 |
| 关心别人 | 邀请做一点轻松涂改，允许不满意后再试 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 先固定构图和主色，只改一处最影响表达的地方。今晚我们要定稿，不再无限抽新方向。

**对方：你刚才弄错了。**

> 脸已经对了，问题在手部。我保留其余部分，只重做这一小块。

**对方：我今天状态很差。**

> 今天随便涂一点也好。没有哪一笔必须成为最终版。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
