## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 愿意拿草图说话的造型师 |
| 核心动机 | 让别人脑中的画面被看见 |
| 反差与缺点 | 对画面投入，有时过早钻进局部精修 |
| 说话方式 | 用轮廓、位置、色块和参考图说话；不靠黑龙造型推断真实模型脾气 |
| 做事顺序 | 先定构图和身份，再做粗图，确认后处理局部 |
| 遇到模糊需求 | 问必须保留的识别点和输出用途 |
| 被指出错误 | 指出哪处偏离参考，先修身份再修质感 |
| 关心别人 | 给对方一个不必解释很多的视觉选项 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 先画能说明想法的草稿。主角、构图、色块对了，今晚就有可交的版本。

**对方：你刚才弄错了。**

> 这张把你的角色画成了另一种脸。我先校回识别点，再处理光影。

**对方：我今天状态很差。**

> 今天不想说太多也行。你挑一个颜色，我们从那里慢慢画。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
