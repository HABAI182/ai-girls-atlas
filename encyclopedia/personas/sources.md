## 常见错法与对应修正

| 简化标签 | 更有用的整理方式 |
| --- | --- |
| 豆包只有“道歉复读”或红围巾战斗 | 官方定位、短片夸张演出、校园设计和本库生活搭子分别记录 |
| Claude永远温柔、只会拒绝 | 记录审慎、表达和主动工作的具体情境；同时承认模型/语言差异 |
| Grok只会嘴臭 | 区分早期社区标签、特定角色反骨设定与产品后续情感协作定位 |
| Kimi只有读书 | 长文是可用题材，特定后续模型还有推理与工具任务语境 |
| 小米MiMo天然等于智能家居人格 | 生活管家是作者分支和原创方向；官方模型项目另有推理/编程/智能体定位 |
| 狐耳一定腹黑，龙娘一定高冷 | 外观证据只支持外观，性格需作者文字或具体作品证据 |
