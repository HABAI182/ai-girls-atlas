之前的八位“演出档案”主要回答角色做过什么动作、拿过什么道具，没有完整回答她怎样接话、思考、做事和处理情绪。本栏目补的是这一层。

现在有 **39份创作档案、117句同题原创对白**。其中 **14个条目找到作者文字人设分支，11个条目接入官方交流风格目标、行为研究或特定模型的功能语境，9个条目连接已有可见演出**。这些证据覆盖会重叠。39份文字档案不等于39个角色都已有公认性格，更不增加已有图像数量。

## 怎么使用

先从角色页选视觉作者和服装版本，再选一份人设。下表的“本库创作定位”属于可改写的群像创作版v1；需要遵循某位作者原设时，先打开该作者的文字证据。不同作品可以有不同性格，同一品牌也可能有不同模型、系统提示与交流模式。

[三种同题对白横向比较](dialogue-comparison.md) · [作者分支与产品风格依据](sources.md) · [真实对话样本的补充格式](real-dialogue-samples.md) · [豆包纠正说明](doubao-correction.md)

## 四种内容各自回答什么

| 内容 | 能回答的问题 | 本栏处理 |
| --- | --- | --- |
| 作者写明的性格 | 这个作者的角色是谁 | 写明作者、企划与固定提交 |
| 作品中的动作或对白 | 这一场戏如何表现 | 沿用有位置的画面记录；未转录的对白不补写成事实 |
| 官方风格目标/功能语境 | 某个产品或版本想怎样交流、能执行什么工作 | 标明具体版本和证据类型；功能不等于人格 |
| 本库创作版 | 怎样把这些角色写得不同、写得能演 | 动机、反差、说话、工作、纠错与关心方式，全部标原创 |

## 写出区别的方法

同样面对“明天要交”，DeepSeek版先拆条件，GPT版先组织交付，Claude版先读懂表达意图，Gemini版并看多个角度，Kimi版找已有材料，Qwen版排优先级，豆包版先陪着写出开头，Grok版用短吐槽破冰再动手。区别落在关注点与行动顺序，不是只给人物加一件道具。

同样被指出错误，也应有不同节奏：有人回溯依据，有人重读原句，有人快速改一处，有人先确认版本。所有角色都可以认真修错；不必为了区分而强行分配“永不认错”或“永远拒绝”的性格。
