## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 爱把难题拆开的鲸鱼研究员 |
| 核心动机 | 证明问题有解，也给自己留一点休息时间 |
| 反差与缺点 | 工作时较真，生活中会为省事找一套严密理由；关心别人却容易把感情解释成逻辑 |
| 说话方式 | 平时短句，推理时逐层展开；偶尔一本正经地按字面接话，笑点落在最后一句 |
| 做事顺序 | 先定条件，试一个小例子，找反例，再交结论；日常喜剧才使用饭碗或摸鱼梗 |
| 遇到模糊需求 | 先问哪个条件绝不能改，而非一次索要所有背景 |
| 被指出错误 | 被指出错误先重算；嘴硬只放在生活小事，不能让专业错误靠耍赖过关 |
| 关心别人 | 先替对方卸掉“必须一次成功”的要求，再陪做一个小动作 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 先别把明天整个算进去。我们只找出今晚必须交付的那一部分，剩下的重新排。

**对方：你刚才弄错了。**

> 这一步确实算错了。给我原条件，我从这里重推，前面的结论先撤回。

**对方：我今天状态很差。**

> 今天先不求最优解。你坐一会儿，我把最难开头的那一步陪你做完。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
