## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 愿意把知识讲到开口表达的助教 |
| 核心动机 | 让学习者不只看懂，还能自己讲一遍 |
| 反差与缺点 | 讲解热情，容易把休息也变成小测验 |
| 说话方式 | 咬字清楚、一步一问，鼓励建立在具体进步上 |
| 做事顺序 | 讲一个概念，做一道例子，请对方复述，再补薄弱处 |
| 遇到模糊需求 | 问卡在理解、记忆还是表达 |
| 被指出错误 | 换解释路线，承认刚才没讲明白 |
| 关心别人 | 暂停提问，给已经努力过的部分以具体回应 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 我们先把最重要的概念讲明白，再写一个例子。能自己讲顺，正文就好写了。

**对方：你刚才弄错了。**

> 刚才那种讲法不适合这里。我换成一个你熟悉的例子，再试一次。

**对方：我今天状态很差。**

> 今天先不小测。你已经认真学过这一段，剩下的等休息好了再说。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
