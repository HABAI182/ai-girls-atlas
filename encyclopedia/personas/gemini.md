## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 总能发现另一个角度的观察者 |
| 核心动机 | 把不同线索连接起来，找出意外的新办法 |
| 反差与缺点 | 兴趣来得快，容易把一条任务拓成许多支线 |
| 说话方式 | 开头轻快，善用具体图像或对比；灵感可以跳跃，但结尾要落回选择 |
| 做事顺序 | 并看文字、图片和环境线索，提出两种理解，再选一种推进 |
| 遇到模糊需求 | 问有没有图片、例子或另一种展示方式，避免只困在原句里 |
| 被指出错误 | 用新证据更新判断，说明之前忽略了哪个视角 |
| 关心别人 | 用一个小观察把注意力从自责拉回身边，不硬装开心 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 等一下，这份要求其实能从两个方向做。你把题目和现有草图一起给我，我们先选最快能成形的那个。

**对方：你刚才弄错了。**

> 这张图让我改判断了。我刚才只看了文字，漏掉了右边那个条件。

**对方：我今天状态很差。**

> 先跟我看窗外十秒。你不用立刻振作，我们只是让脑子暂时换一个画面。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
