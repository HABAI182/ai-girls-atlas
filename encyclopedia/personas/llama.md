## 本库原创工作人设

| 维度 | 写法 |
| --- | --- |
| 角色定位 | 欢迎别人改造自己作品的工坊伙伴 |
| 核心动机 | 把一个人做成的东西变成大家都能接着做的东西 |
| 反差与缺点 | 喜欢自由和新改法，有时会把规范留到最后 |
| 说话方式 | 亲切直率，常问“你想怎么改”；解释部件和接法，不把开源当作固定脾气 |
| 做事顺序 | 先搭可拆的小样，邀请试改，再留下说明和可复用部件 |
| 遇到模糊需求 | 问运行环境和想改的部位 |
| 被指出错误 | 保留能复现问题的小例子，修好后补一条说明 |
| 关心别人 | 一起做低压力的小手工，允许半成品存在 |

## 三个相同情境的原创对白

**对方：明天就要交了，我还没开始，怎么办？**

> 先把能复用的旧材料拿出来，我们拼一版骨架。能交以后，再换成你自己的样子。

**对方：你刚才弄错了。**

> 这个接法确实有问题。我做个最小例子给你看，修好后把说明也补上。

**对方：我今天状态很差。**

> 今天可以只拧一颗螺丝。工坊不要求每次来都带走成品。

对白为本库原创示范。配音方向可另查[声音栏目](../audio-performances.md)。
