# 三个原创短剧：把素材变成一场戏

[创作百科](README.md) · [八位角色的四情境点子](performances/same-situation.md) · [素材关联包](production/README.md)

以下为本库原创脚本提案，不是已有视频的剧情转录，也不指定配音。时长是写作目标，尚未通过演出计时；角色关系仅属于这三则提案。可以沿自己选择的作者版本改写。

## 一、最后一碗白饭

角色：DeepSeek、GPT、Qwen。场景：厨房一张桌。道具：饭锅、三个碗、任务单。目标约45—60秒。

| 段落 | 画面与动作 | 原创对白 |
| --- | --- | --- |
| 开场 | DeepSeek把空碗倒扣，锅里只剩一碗饭。GPT把三只碗依次排好。 | DeepSeek：先声明，我还没吃。 |
| 建立任务 | Qwen将一张“谁洗碗”的任务单摆在饭锅旁。 | Qwen：最后一份，给洗碗的人。 |
| 第一次转交 | GPT把任务单推给DeepSeek。DeepSeek伸手接单，另一只手悄悄碰饭勺。 | GPT：这件事交给最熟悉厨房的同事。 |
| 第二次转交 | DeepSeek把任务单折成小纸飞机，准备送向Qwen。 | DeepSeek：我申请一个更熟悉洗碗的同事。 |
| 阻碍 | Qwen用合着的扇子压住纸飞机，将单子转回。 | Qwen：饭可以分，活不能只分出去。 |
| 选择 | DeepSeek看锅、看三只碗，把饭分成三小份。GPT递洗碗布，Qwen挽袖。 | DeepSeek：那就每人一口，每人洗一个。 |
| 收束 | 三人举碗。DeepSeek忽然看向盛饭的锅。 | DeepSeek：等一下，锅算谁的？ |

演出重点：开场先看懂“饭不够、碗有三个”。任务单每传一次，人物关系就改变一次。最后回到锅，回收同一道具。无需每句都解释token或代理。

最小素材：三张半身立绘、DeepSeek期待与心虚两种表情、GPT平静表情、Qwen持扇姿态、一个桌面背景。若只有单张立绘，可把变化集中在手部道具和视线。

## 二、谁把门牌换了

角色：Claude、DeepSeek、GLM。场景：办公走廊及两扇相邻门。道具：可翻转门牌、任务信封。目标约60—75秒。

| 段落 | 画面与动作 | 原创对白 |
| --- | --- | --- |
| 开场 | Claude敲写着DeepSeek的门，GLM探出头。 | Claude：我找DeepSeek。／GLM：信封上写的却是我。 |
| 第一处矛盾 | 特写：信封正面写DeepSeek，门内的投递槽写GLM。 | Claude：我出门前检查过。 |
| 另一边 | DeepSeek从相邻门探头，手中抱着空饭碗。 | DeepSeek：有人叫我开工吗？ |
| 误会升级 | 两人把信封同时交给对方。GLM托住掉落的文件。 | GLM：先别互相转了，看看信是怎么走的。 |
| 排查 | Claude沿地面箭头走到走廊中间。箭头末端分叉，门牌可翻转。 | Claude：名字没写错，最后一段路被改过。 |
| 解决 | 三人依次摆正箭头、门牌与信封。 | GLM：任务先放桌上。／DeepSeek：饭也能放桌上吗？ |
| 结尾 | Claude翻过门牌，背面写着“厨房”。两人一起转头看DeepSeek。 | DeepSeek：这个真是我改的。 |

演出重点：把路由误会转成看得见的门、箭头和信封。笑点来自最后一项确实是主角干的，不靠旁白讲完整技术架构。

最小素材：三位角色各一张站姿；门口背景；门牌正反、信封与方向箭头。技术故障只是创作隐喻，不声称复述真实事件。

## 三、今天先别升级

角色：Gemini、Kimi、Claude。场景：夜间工作桌。道具：两张方案卡、一盏月形灯、一本工作簿。目标约45—60秒。

| 段落 | 画面与动作 | 原创对白 |
| --- | --- | --- |
| 开场 | Gemini把两张方案卡举得一样高，又各翻一面，桌面已经铺满版本号。 | Gemini：还有一个更好的方案。 |
| 小动作 | Kimi从一摞卡片下面抽出被压住的杯垫。 | Kimi：先把杯子放稳。 |
| 共同问题 | Claude翻开工作簿，第一页还是空白。 | Claude：我们今天最初要做什么？ |
| 停顿 | Gemini缓缓放下两张卡。三人看向空白第一页。 | Gemini：做完第一版。 |
| 改变 | Kimi把月形灯转向其中一张卡；Claude在第一页写下一个勾选框。 | Kimi：今晚只照这一张。 |
| 完成 | Gemini把另一张卡收进明天的文件夹，三人共同勾选一项。 | Claude：这里留给明天。 |
| 尾声 | 灯熄前，Gemini又拿出一张小卡，看见同伴便悄悄收回。 | Gemini：只是记一下，不升级。 |

演出重点：用卡片数量与桌灯方向表现“不断换方案”到“先做完一件事”。情绪由物件与视线推进，最后保留一个轻微反复的小动作。

最小素材：三位半身立绘、Gemini犹豫与放松两种表情、固定工作桌、卡片和台灯。避免把反复改方案写成某个真实模型的固定缺点。

## 和现有素材怎样对应

- 对白前先从[实际演出档案](performances/README.md)挑姿态，确认它属于静态图还是动画参考。
- 同一场戏尽量选同作者或明确兼容的版本；不同画风混用时，可统一做卡片/贴纸形式。
- 若暂时没有角色声音，先用文字台本和分镜卡表达完整因果，不把未选定的声线写成完成配音。
