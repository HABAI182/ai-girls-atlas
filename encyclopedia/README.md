## 本轮如何复用旧资料

保留原有82张图片、43条作者版本、视频案例与项目评述；新增的是作品语境、材料关联和本轮查到的具体入口。没有把同一张图片重新复制成多个栏目文件。

## 看清三种内容

**作品事实：**实际查看的图像、抽帧、作者页面和具体文件入口。

**作者说明：**制作流程、模型功能和运营方式由发布者陈述，必要时单列。

**本库原创：**32格演出点子、五句试声文本和三个短剧，均是创作参考，未冒充社区原设。

## 已完成的边界

栏目和整理工作已落地。公开分发入口已找到不等于已领取或运行模型；音轨机器分析也不等于人耳试听。薄弱角色没有查到确切新方案时保留结果，避免用猜测填满。
