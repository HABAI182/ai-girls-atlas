# AI娘都在玩什么梗

[创作百科](../README.md) · [动作与道具](../actions.md)

十个专题都接入具体作品。这里整理语义、画面变体和创作方式；记录到的样本不等于全网起源。

| 专题 | 核心含义 | 作品样本 |
| --- | --- | --- |
| [Token投喂／吃完Token还要饭](token-as-food.md) | 把模型用量转译为AI娘的食欲：用户付出的调用资源像喂食，消耗之后的空盆或讨要动作，把成本体验变成可见的关系笑点。标题能支持token语义，画面本身只展示角色与盆勺，不能把盆里每一粒食物换算成真实token。 | 2 |
| [白饭鲸鱼／家里遭了蓝色大肥鱼](rice-eating-whale.md) | 把鲸鱼娘缩小后放入真实厨房，用大米减少和吃饱躺倒表现贪吃。它属于角色入侵现实生活的夸张幻想；是否可解释为token消耗，需结合具体作品标题，不能见到米饭就自动套用技术含义。 | 2 |
| [蒸馏梗／室友间的借鉴被抓包](distillation-housemate-tension.md) | 把模型蒸馏这一技术词改写为角色间的借用、模仿或被指责关系。在合租故事里，它可以成为日常相处的冲突；在配对OP里，蒸馏模型又被标题包装为亲密关系隐喻。这里只记录作品写法，不据剧情认定现实模型存在任何具体训练或侵权行为。 | 2 |
| [SOTA失恋／败犬AI](sota-losing-ai.md) | 将排行榜领先与被超越改写为校园中被落下、失落和继续生活的情绪。这种人格化让技术竞争可进入青春群像。作品简介直接使用SOTA语义，抽帧只验证校园包装和情绪场景；不把虚构排名或日期当作模型评测事实。 | 2 |
| [半场开香槟／第二名的颁奖反转](premature-celebration.md) | 观众期待角色夺冠，作品却先说亚军并在末尾给出投票界面，以期待落差完成自嘲。这里的竞争属于女神投票，不是技术性能榜；把票数当模型能力会混淆作品的笑点对象。 | 2 |
| [中转站背锅／谁把模型换了](relay-routing-blame.md) | 把请求模型与实际执行模型不一致写成抢活或误会：用户怀疑某个AI娘，作者最后把原因归到中转站映射。该样本实际包含大量调用记录、文档和界面讲解，不能只看标题就归为完整角色争吵短剧；路由原因是作者经验叙述，本轮没有复现配置。 | 3 |
| [工作转包／摸鱼后请别的AI娘代劳](delegation-and-slacking.md) | 用户给DeepSeek分配翻译任务，DeepSeek却坐下叫来千问处理；角色把代理调用关系演成办公室转包。画面可支持任务移交与放松姿态，摸鱼是编者对喜剧效果的概括，不证明产品在真实请求中故意偷懒。 | 2 |
| [用户彻底怒了／反过来AI娘向用户算账](user-ai-power-reversal.md) | 开场把用户放在分配任务的位置，中段让观众预期用户回来训人，随后AI娘却以token消耗提出加价。权力位置在同一场景里倒转，最后惊讶表情落在用户一方。怒了是作品标题与画面字幕的包装，不能据此描述真实用户情绪或产品收费。 | 2 |
| [月初神仙／月末笔仙](monthly-budget-ritual.md) | 用月初、月中、月末三段，把从容使唤AI、代码问题和月底求助串成资源逐渐收紧的生活笑话。预算和额度耗尽是可作的编者解释，不等于视频证明了具体订阅制度；同一个银色短发用户贯穿各段才是可见叙事骨架。 | 3 |
| [蓝色大肥鱼／昵称成为角色自嘲](big-blue-fish-nickname.md) | 把DeepSeek鲸鱼娘称作大肥鱼，是本轮多个标题和字幕中反复出现的角色昵称。它可与贪吃、Q版体型、饭盆道具结合，也可用于观众呼喊和角色自嘲。本轮只确认这些使用方式，不给出昵称的首创者或最早传播日期。 | 3 |

同一个米饭道具在不同作品里可以是生活、消耗或报酬隐喻，按作品分别解释。
