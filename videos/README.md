## 怎样使用这些分析

1. 先选内容目的：让人笑、看关系、看舞台、理解一个功能，或找到制作资料。
2. 再选画法：白底卡片、生活场景、都市战斗、像素、模型画册等。
3. 检查手上的作者版本能否支持：一张立绘、多表情、同作者Q版/常规、三视图或工程包。
4. 回到案例时间点看具体安排，再去原作者找素材；保留形象、动作、歌曲与模型各自署名。

## 本轮观察范围

每篇均实际查看采样联系表，部分追加原帧；短片通常先按1fps生成，再选约15帧检查，并非逐帧看完所有帧。实体手工20分钟长片按60秒间隔取样。所有音频未试听，因此不评价音色、演唱、台词节奏或口型同步。时间链接帮助原片复看，正文把可见事实、作者自述与编者归纳分开。

《败犬AI太多了》有两个分P，总时长182秒；本轮只研究首P91秒。片中的虚构职员表、架空未来版本和模型笑话均保留在作品语境内。

播放数是读取时快照，只用于本库候选内的导航；未为凑榜单重抓所有旧视频。截图和完整视频留在本地研究区，公共仓库发布原创分析及来源链接。
