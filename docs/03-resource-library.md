## 怎样检索才容易找到合适的图

先按角色和作者版本缩小范围，再按作品类型、情绪、动作、台词检索。适合聊天的反应图需要小尺寸可读；适合二创的参考图需要结构清楚。二者不是同一个质量标准。

建议检索词：`AI娘化`、`模型娘`、`大AI和小AI们`、`鲸鱼娘`、`Whale-chan`、`AI gijinka`、`moe personification`；再加具体作者、产品名、三视图、Q版或表情包。

搜索结果、聚合转载、作者原作和官方资产应当逐层回溯。不要把同一转载链中的三个网站计成三个独立起源证据。
