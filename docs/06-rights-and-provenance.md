# 文件来源与使用状态

本页记录已找到的声明及本仓库的实际收录决定，不替任何原作者补充许可。产品名称与商标不因拟人化或公开收录而改变归属。

## 本库怎样分类

| 状态 | 含义 | 本库处理 |
| --- | --- | --- |
| `CC-BY-NC-SA-4.0` | 有具体声明，要求署名、非商业、改编同协议 | 记录声明页和署名链；文件保持原字节 |
| `author_sharing_statement` | 作者说可分享、再创作，未核实标准许可证 | 展示这项原话的出处，不擅自变成 MIT、CC0 或可商用 |
| `maintainer_declared` | 项目维护者对指定文件作出许可声明 | 记录逐文件声明，保留其权利范围限制和上游署名 |
| `site_claim_only` | 只有聚合站或投稿字段中的标记 | 先保留原作入口，不冒称已完成作者许可核验 |
| `unknown` / 空字段 | 许可没有记录或不足以判断 | 外链索引，不自动下载入公开素材包 |
| `official_reference` | 产品官方头像或品牌材料 | 与同人独立，链接到官方来源；不当作开放素材 |

CC 摘要和完整条款入口见 [Creative Commons](https://creativecommons.org/licenses/by-nc-sa/4.0/deed.zh-hans)。仓库公开与素材可商用是两个不同状态。

## 已收录的两条主要素材链

**ZipZipPipe 系列。** 从 `shuaizenge/ai-girls` 固定 Git 树取回立绘、变体和 Q版展示截帧；源文件与其公开校验值逐一比对。作者的原始发布与实际文件供应方都在 `data/assets.json` 中保存。DeepSeek 采用上善无形原角色与 ZipZipPipe 二次设计的完整署名；其他角色保留作者在《“亿万”身家的她们》中的开放分享、再创作声明，不套用未经声明的统一标准许可证。

**JAdpp 系列。** 取回项目明确列入 CC BY-NC-SA 4.0 的六张角色立绘及八张鲸鱼娘表情。维护者声明仅在持有相应权利范围内许可。DeepSeek 的上游链包含上善无形、ZipZipPipe、Small-tailqwq / dsh-deep-whale；其他五位是 JAdpp 的独立 AI 辅助设计，不能标为 ZipZipPipe 原版。上游许可证和 NOTICE 保存在 `licenses/upstream/jadpp/`。

本库对以上文件没有重画、裁切或重新压缩；只调整目录名称。九张预览为上游已经缩小的文件，另存其校验值。其中Seed立绘按原图明确的SEED工牌纠正了上游角色分类，原始字节与上游分类均保留记录，见[data/corrections.json](../data/corrections.json)。Q版文件是原作者视频展示的完整截帧，绝不标成原始透明立绘。

## 如何署名

引用时把姓名、原帖、设计版本、许可链接和改动说明放在作品附近。例如：

```text
角色原型：上善无形；DeepSeek 女仆二次设计：ZipZipPipe。
具体文件来源与下载供应方：见 assets.json 对应记录。
本次修改：{如实填写；未修改则写原文件保留}。
许可：CC BY-NC-SA 4.0，附许可链接。
```

如果使用 JAdpp 的表情或立绘，还需保留该文件列出的上游和改编者。仓库维护者不是这些角色的作者；提示词、生成工具和文件供应方也各有独立身份。

## 更正与移除

请通过本仓库 Issue 提供文件路径、诉求和可核实的来源。优先处理署名纠错、原帖替换和具体作品下架。涉及文件移除时同步更新索引与校验值，避免留下指向不存在文件的目录。

本仓库原创说明与程序的许可见根目录 `LICENSE.md`，第三方图片继续适用本页和逐文件记录，不被根目录许可覆盖。
